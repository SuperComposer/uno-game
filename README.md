# Project Name

This is a multiplayer uno game that friends can meet up to play together.

## The Problem

Oftentimes at a party, playing board games or card games can require a long time to set up and clean up. On top of that, shuffling always remains a problem as either nobody is good at it or someone will complain about 'luck'.
One way of getting rid of time lost is by making the game digital, which is why this game is being created.

## How It Works

This project is coded in java.
A card class is created taking properties of a card.
A deck is created and shuffled at the beginning.
7 cards are dealt to each player
Rules of UNO are the same as the card game
Gameplay continues until a player has no cards left
If a player has no cards left, that player is the winner and the game ends.
